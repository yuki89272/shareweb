# 萬數屋 導覽影片 — 使用說明

一個平板網頁介面，流程如下：

**封面（會動的場景，點門或「開始導覽」）→ 導覽介紹（故事分段，可跳過）→ 八個展件按鈕 →（點按鈕）→ 全螢幕播放導覽影片。**

有兩種播放方式，可以切換：**連網路看 YouTube**（部署成網址給大家用），或**平板離線播放本機影片**（不用網路）。切換方式見下方「二、兩種播放模式」。

- 封面：房子、熱氣球、蝴蝶、雲、落葉都會動；點中央「開始導覽」進入。
- 導覽介紹：故事分段自動播放，輕觸畫面可加快，右上「跳過介紹」可直接進按鈕頁。

## 檔案結構
```
萬數屋導覽/
├── index.html        ← 主程式（要填影片、切換模式都是改這個檔）
├── assets/           ← 圖片素材（八個按鈕、logo、封面主視覺）
│   └── videos/       ← 本機播放模式用，八支 mp4 放這裡（見下方「二」）
└── 使用說明.md        ← 本檔
```

## 一、填入影片（已完成，備查）

八支影片已上傳 YouTube，設為「**不公開 (Unlisted)**」（頻道沒開營利，所以沒有廣告），影片 ID 也都已經填進 `index.html` 的 `const ZONES = [...]` 裡。之後如果要換影片、補拍新的，流程一樣：

1. 新影片一樣上傳 YouTube，設「不公開 (Unlisted)」。
2. 網址 `https://youtu.be/AbC123xyz` 最後那段 `AbC123xyz` 就是「影片 ID」。
3. 打開 `index.html`，在 `const ZONES = [...]` 裡找到對應展件，把 `id:"..."` 換成新的 ID：

   ```js
   { key:"huanying_lun", title:"幻影輪",  id:"AbC123xyz" },
   ```

   留空 `id:""` 的展件會顯示「即將上線」。

## 二、兩種播放模式

`index.html` 裡靠近 `const ZONES = [...]` 上方有這一行：

```js
const VIDEO_MODE = "youtube"; // "youtube" | "local"
```

- **`"youtube"`**（目前設定）：點按鈕播放上面填好的 YouTube 不公開影片，**需要網路**。這份用來部署成網址給大家連線看。
- **`"local"`**：改成播放平板本機存的影片檔，**完全不用網路**。切成這個模式前，要先把八支影片轉成 mp4，放進 `assets/videos/` 資料夾，檔名用展件的 key（對照表見「一」），例如：

  ```
  assets/videos/huanying_lun.mp4
  assets/videos/zhongxin.mp4
  ...（其餘 6 支依此類推）
  ```

這兩種模式通常分成**兩份獨立使用**，不是同一份網頁讓現場切換：一份 `VIDEO_MODE="youtube"` 部署上網，另一份 `VIDEO_MODE="local"` 連同 `assets/videos/` 一起複製到平板裡離線用。

## 三、修改導覽介紹文字（選用）

故事文字寫在 `index.html` 的 `<section id="story">` 區塊裡，每一段是一個 `<div class="seg">`。
直接改文字即可；要增減段落就整段複製或刪除一個 `<div class="seg">…</div>`（下方進度點會自動對應數量）。
自動換段的秒數在 `<script>` 的 `showSeg()` 函式裡（`delay`）。

## 四、連網路版：變成一個網址（讓學校打開用）

確認 `VIDEO_MODE = "youtube"` 後，把整個 `萬數屋導覽` 資料夾上傳到任一免費靜態網站空間，就會得到一個網址：

- **最簡單**：Netlify Drop（https://app.netlify.com/drop）— 把資料夾直接拖進去，馬上得到網址。
- 其他：GitHub Pages、Cloudflare Pages 等皆可。

拿到網址後，平板用瀏覽器打開，可「加入主畫面」，用起來就像一個 App。

⚠️ **測試注意**：不要直接雙擊 `index.html` 用本機檔案（網址列會是 `file://...`）測試 YouTube 播放，YouTube 嵌入在這種情況下會出現「影片播放器設定錯誤（錯誤 153）」。要測試請用 `http://localhost` 本地伺服器（在資料夾裡執行 `python3 -m http.server 8000`，瀏覽器開 `http://localhost:8000`）或直接用部署後的正式網址。

## 五、離線版：裝進平板

把 `VIDEO_MODE` 改成 `"local"`、`assets/videos/` 放好八支 mp4 之後，不用部署，直接把整個 `萬數屋導覽` 資料夾複製進平板裡：

- **一般電腦**：資料夾直接拖曳過去，用瀏覽器開本機 `index.html` 即可，相對路徑都通。
- **iPad**：`file://` 本機開啟在 iOS Safari 上不太穩定（影片自動播放、路徑解析偶有問題）。比較保險的做法是裝一個免費的「本地 HTTP Server」App，把這個資料夾指給它當根目錄，再用 Safari 開它給的 `http://localhost:xxxx` 網址，效果會跟部署版一樣穩。建議正式展場用的那台 iPad 要先實測過一輪再上場。

## 六、給學校的使用方式
- **一台共用**：平板停在封面當待機畫面，有人來點「開始導覽」即可。
- **人手一台**：每台平板都開同一個網址（或本機版），各自點選觀看。
- 請橫向使用（影片為橫式）；直向時會提示轉為橫向。

## 七、備註
- 連網路版影片放 YouTube unlisted，頻道沒開營利就不會有廣告；離線版則完全繞過 YouTube，播放本機 mp4。
- 若要更換按鈕圖示或封面，替換 `assets/` 內對應檔案即可（保持相同檔名）。
