# 數學展提案 — 內容風格規範

> 目的：避免簡報讀起來像 ChatGPT 產的內容行銷文。
> 原則：**口號濃度要低；具體名詞濃度要高。**

---

## 一、整體準則

簡報的可信度來自「細節」，不是「金句」。提案人不會比設計公司更會講話，但會比他們更懂自己的內容。每一頁問自己：**如果把口號刪掉，剩下的東西夠不夠站得住？**

- 一份 22 頁的簡報，**真正的「金句」最多 3 個**——封面、核心命題、結尾各一個。其他地方都應該是具體內容
- 句子越短越像金句，但金句太多會稀釋；務必克制
- 同一個修辭結構（如「從 X 到 Y」）整份簡報**最多用一次**

---

## 二、禁用 / 慎用清單

### 禁用（這些是 AI 生成文的招牌）
- ❌ **「從 X 到 Y」反覆使用**：可在封面或核心命題出現一次，其他地方禁
- ❌ **破折號 + 三段排比**：「A、B、C」+「——」這種句式是 GPT 招牌
- ❌ **「翻轉」「翻轉為」「轉化為」「重新定義」**：抽象動詞，等於沒講
- ❌ **「情緒旅程」「情緒弧線」「情感連結」**：當概念說明可，但不當頁面標題
- ❌ **連續 OS 引號當標題**（「哈哈我懂！」、「原來這也是！」⋯⋯四連發）：一個是巧思，多個是公式

### 慎用
- ⚠️ **驚嘆號**：整份簡報控制在 5 個以下
- ⚠️ **「讓⋯⋯」開頭句**：「讓觀眾」「讓數學」「讓人」——用一次有力，三次以上就是空話
- ⚠️ **形容詞堆疊**：「荒謬」「痛快」「驚訝」「好玩」並列出現時，至少砍掉一個

## 三、寫法替換建議

| 原寫法（口號型） | 改寫方向（具體型） |
|---|---|
| 從反感翻轉為好奇 | 把這些題目當主角，不是當反派 |
| 讓課本中的數學活過來 | 把雞兔同籠的籠子做成 1:1 實體（保留即可，但別重複） |
| 看到雞兔同籠想翻桌、被買 87 顆西瓜的大叔氣笑、第一次發現生日悖論時的驚訝 | 改：「雞兔同籠的籠子、87 顆西瓜的牆、生日撞檔的入場儀式」——具體展品名 |
| 觀眾從頭走到尾經歷四段情緒轉折 | 動線設計上分四個階段（共鳴 → 發現 → 視野 → 動手） |
| 把那些荒謬的角色當成主角 | 第一展區聚焦五個課本人物：農夫、買瓜大叔、種樹的、追相遇的、強迫症包裝大師 |

## 四、頁型 × 文案密度建議

| 頁型 | 金句可以多重 | 具體內容要求 |
|------|------------|------------|
| 封面 | 可以一句重口號 | — |
| 章節隔頁 | 短標 + 一句說明，不要堆 | — |
| 核心命題 | **整份唯一的大金句**，所有彈藥押在這 | — |
| 展區概念頁 | 一個短句點題即可 | 必須有具體展品名 / 互動方式 / 數字 |
| 旗艦展品頁 | 標題可以略玩文字 | Hook + 互動描述要直白可執行 |
| 大數字頁 | 數字本身是金句，文字退到說明 | — |
| 時間軸 / KPI | 不准用金句 | 條目越具體越好 |
| 結尾 | 可以一句溫度句 | — |

## 五、本次 P2 / P4 / P5 文案稽核

### P2「這份提案要說什麼」
- ✅「2026/12 開展 / 4+1 區 / 33 件」三個數字已經是具體錨點
- ⚠️「從『蛤』到『哇』」目前出現在 P2、P5，**應該只留 P5**（且 P5 也再評估）
- ⚠️ stat 描述句「組成從『蛤』到『哇』的情緒旅程」改成具體：「依觀眾動線編排，主展區四 + 跨展區一」

### P4「核心命題」
- ✅「討厭到一種極致也是好玩」是合格的金句，保留
- ❌ 下方說明文有 GPT 句型（破折號 + 三段排比 +「翻轉為好奇」），需重寫
- 改寫方向：去掉抒情，給一個具體的展品例子當證據。例如：
  > 整個展覽從一個簡單的觀察開始：每個人都討厭過數學，
  > 但討厭得越深，那些題目反而越難忘。
  > 雞兔同籠的農夫、買 87 顆西瓜的大叔——
  > 我們把這些角色當主角，而不是當反派。

  （只用一個破折號，不堆三段，沒有「翻轉」字眼）

### P5「情緒弧線總覽」
- ❌「情緒弧線」這個詞本身就是抽象修辭。**改頁名為「觀眾動線」或「四段觀展節奏」**
- ❌「從『蛤……數學……』到『哇！數學！』」如果 P2 拿掉了，這裡可以保留一次
- ❌ 四個 OS 引號標題是公式化的並列。**保留結構，但改成展區描述句**，OS 只當小副標：
  - 01 數學哏 ｜「共鳴」｜ 找回課本記憶
  - 02 生活中的數學 ｜「發現」｜ 原來它一直都在
  - 03 各行各業的數學 ｜「視野」｜ 數學能做什麼
  - 04 探索包動手玩 ｜「體驗」｜ 帶東西回家

## 六、出處（cite）紀律

**症狀**：頁面上的一筆數據刪掉了，下方 cite 卻還掛著那筆來源——投影片上根本找不到那個數字，出處卻寫得煞有其事。等於引用了一個沒出現的東西；老師講到那頁被問「這個資料在哪」，答不出來。

**根因**：改頁面時，「刪內容」和「改出處」是兩個動作，人只會記得做第一個。cite 又在頁面最下方、字小、顏色淺，改完不會再看它一眼，於是留下一筆孤兒出處。

**規則**：**cite 只列這一頁上真的看得見的數據來源。**

- 刪掉一筆數據 → **同一次編輯**就把它的出處一起刪掉。
- 補一筆數據 → 同一次編輯就把出處補上。
- 一筆來源同時撐好幾個數字：只要還有任何一個留在頁面上，出處就留著；全刪光了才刪出處。
- 出處是給人查證用的，不是拿來墊頁面份量的。**頁上沒有的東西，不要出現在 cite。**

**收尾自查**（每頁改完問一次）：把 cite 逐條念出來，每一條都能在這頁指出「它撐的是哪一個數字」嗎？指不出來的那一條，刪掉。

〔來源：財務課簡報，刪掉資料後 cite 沒跟著刪〕

## 七、自我檢查清單（每頁完成前過一遍）

1. 這一頁有沒有具體名詞？（展品名、數字、地名、人物）
2. 有沒有「從 X 到 Y」「翻轉」「情緒」這類抽象詞？刪掉看看會怎樣
3. 修辭句型重複了嗎？（破折號、三段排比、OS 引號）
4. 金句濃度——這頁有幾個？整份簡報目前累計幾個？
5. 把這頁讀給一個不認識展覽的人聽，他能複述出「這頁在講什麼」嗎？
6. cite 每一條都對得上頁面上看得見的數字嗎？（刪過資料的頁一定要再看一次，見 §六）

## 八、每頁字數與頁面公式（2026-09-06 新增）

**症狀**：AI 產出的簡報，習慣把講稿的論點整段搬上投影片。看起來「資訊充足」，投影出來字太小、聽眾在讀字不在聽你講，講者也被自己的投影片綁住。

**根因**：AI 手上有完整的講稿，會誤以為投影片要「涵蓋」講稿。**投影片不是講稿的縮圖，是講稿的索引。**

### 實測基準

以 `AI與教育／ai-education-math.html`（59 頁，老師定版、實際講過）為基準量測：

| 指標 | 基準值 |
|---|:---:|
| 每頁可見中文字**平均** | **66** |
| **中位數** | **47** |
| 單頁最大 | 179 |
| 圖片密度 | 79 張 / 59 頁 ≈ **1.3 張/頁** |
| 動畫 class 出現次數 | 約 340（anim-up 72、anim-bar 46、anim-stagger 37…） |

**目標：平均 ≤ 80、中位數 ≤ 70、單頁硬上限 140。超過 120 字的頁不要多於總頁數的 15%。**

> 量測指令見 `AI-START-HERE.md` §5。**不要憑感覺判斷「這頁字會不會太多」，跑一次就知道。**

### 頁面公式（照這個組，不要自由發揮）

```
page-hero        一個大問句或大主張        ← 全頁只有這一個大字
cite             一行出處（可選）
內容容器 .anim-stagger
  ├ 圖 ＋ 文字列
  │   eyebrow    標籤，10 字內
  │   pill       數字徽章，如「無護欄　−17%」
  │   lead       一句話，20 字內
  │   body       最多再一句，20 字內
  └ 最多 2–3 列，不要 4 列以上
page-foot        一句收尾，關鍵詞包 <b>    ← 整頁的落點
```

### 砍字的五條紀律

1. **砍掉的字移進 `plan-note__source`，不是刪掉**——講者本來就會講，那是逐字稿該待的地方
2. **條列句改標籤**：「後段學生做不來？→ 中國縱貫實驗顯示後段進步幅度更大」→ eyebrow「做不來？」＋ pill「後段進步更大」
3. **引文只留最有殺傷力的那一句**，其餘進 plan-note
4. **一頁最多 3 個內容塊**。超過就砍內容，**不是縮小字級**（字級有 2u 底線，砍字才是正解）
5. **說明交給圖片**。用隱喻照片替投影片省字——「AI 是獲得解答的直達車」配一張木頭玩具小火車直達終點站的照片，比寫三行解釋有效

### 圖片的角色

參考版的圖多半**不是資訊圖，是隱喻照片**（直達車＝卸載思考、沒被按下的服務鈴＝被動等待）。這種圖不需要圖說也看得懂，而且能讓文字降到一句。
**平台截圖、論文圖、數據圖照放**，但它們替你省的字有限；一份簡報如果只有這類圖，字數一定壓不下來。
